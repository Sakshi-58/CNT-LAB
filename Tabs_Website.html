VIT: SDP, EDI, DT & Course Projects

SDP: Software Development Project

At VIT, SDP helps students build real-world software applications. It improves teamwork, coding ability, version control skills, and full-stack development.

  • Learn SCRUM/Agile
  • Build real deployable software
  • Use GitHub, Docker, Cloud
  • Work in teams like the industry

EDI: Entrepreneurship Development & Innovation

EDI at VIT encourages innovation, startup thinking, problem identification, and pitching ideas.

  • Business model creation
  • Understanding market needs
  • Designing MVP (Minimum Viable Product)
  • Pitching to investors and faculty panels

Design Thinking (DT)

DT helps students approach problems creatively with empathy and innovation.

  • Empathize with users
  • Define the problem
  • Ideate unique solutions
  • Prototype & test ideas

Course Projects at VIT

Every semester, students complete projects in courses such as AI, ML, Cloud Computing, Web Dev, IoT, DBMS, etc. These projects strengthen understanding and practical skills.

  • Enhances hands-on learning
  • Improves coding & problem-solving
  • Useful for resume & placements
  • Builds creativity and technical depth
